# Plain `torch` here resolves to the CPU-only build from PyPI, which is the
# right default: it works everywhere and needs no CUDA install.
#
# For GPU, install a CUDA build INSTEAD, after installing this file. Releases
# are built against cu124, so that is the best-tested choice:
#   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu124
#
# IMPORTANT: a CUDA torch alone only accelerates translation (NLLB). Speech
# recognition runs on faster-whisper -> CTranslate2, which bundles no CUDA of
# its own and needs the NVIDIA driver plus CUDA Toolkit 12.x and cuDNN 9.x for
# CUDA 12 installed on the system. Install those first, or transcription
# silently stays on CPU (or fails) while the app still reports "cuda", because
# the device check uses torch as a proxy for both engines. See the README.
torch
# RealtimeSTT — local real-time transcription with dual VAD + two-pass models.
#
# Pinned to our fork's `faster-whisper-engine-options` branch, and this is
# REQUIRED rather than a nicety: realtime_stt_mixin.py passes
#   transcription_engine_options={"model": {"local_files_only": True}}
# to keep startup fully offline. Upstream *accepts* that argument but its
# faster_whisper adapter silently ignores it, so on stock upstream the app
# reaches out to Hugging Face on every launch and raises no error to explain
# why — a silent behavior regression rather than a visible failure. The fork
# only adds that pass-through (see its commit "Honor engine_options in the
# faster_whisper engine"); it is otherwise stock RealtimeSTT 1.0.2.
#
# Once the upstream PR lands, drop the URL and pin the release that has it.
# For a GPU build, add the extra: RealtimeSTT[gpu] @ git+https://...
#
# Developing against the fork itself? Install it editable instead of this line:
#   git clone -b faster-whisper-engine-options https://github.com/TopGradeTech/RealtimeSTT.git
#   pip install -e path/to/RealtimeSTT
